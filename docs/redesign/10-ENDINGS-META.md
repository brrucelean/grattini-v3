# 10 — Finali e metaprogressione

## Stati

Game over, run vinta, vittoria combat, cedole, trofei, reliquie, vintage, statistiche e modali residui.

## Direzione

Finali come vere schermate editoriali pixel-art, non overlay sul gioco. La meta usa archivio/ricevute/timbri coerenti con il mondo di Grattini.

## Gate

Tutti i risultati e sblocchi mostrati; navigazione di ritorno sicura; statistiche leggibili; nessun componente legacy isolato; regression test dell'intera run.
