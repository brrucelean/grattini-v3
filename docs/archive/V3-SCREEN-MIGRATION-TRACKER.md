# V3 screen migration tracker

Method: redesign one complete screen at a time. Each screen must pass build, interaction and visual review before the next begins. Gameplay and content stay unchanged.

## Order

- [x] Title and nail tutorial
- [ ] Map, nodes, route states and top news ticker
- [ ] Combat: intent, cards, timing, enemy and nail selection
- [ ] Scratch overlay shell and common scratch interaction
- [ ] Every scratch-ticket family and its unique grid/win logic
- [ ] Nails, hand, states, implants and scratch tools
- [ ] Shop and inventory
- [ ] Events and every dialogue variant/exclusive
- [ ] Inn and rooms
- [ ] Cell, game over and victory
- [ ] Trophies, relics, vintage, statistics and remaining modals
- [ ] Full-run regression and final visual audit

## Acceptance for each screen

1. All original content and gimmicks are present.
2. Keyboard, pointer and touch paths still work.
3. The 640×360 logical composition has no accidental reflow.
4. Symbols and actions are legible without relying on color alone.
5. No soft blur, glass panel or generic neon-card treatment remains.
6. Visual review is performed on the complete screen, not isolated components only.
